# Domain docs

CMD Riker uses a single domain context.

Before exploring or naming a concept, read root `CONTEXT.md`. Read relevant records under
`docs/adr/` when that directory exists. Missing ADRs are not a setup error; create one only after a
hard-to-reverse, surprising trade-off has actually been decided.

Use the glossary's canonical terms in issue titles, specifications, modules, and tests. When a needed
concept is absent, invoke `/domain-modeling` rather than silently introducing a synonym.
